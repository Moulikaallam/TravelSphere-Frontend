# TravelSphere — Frontend Travel Website

A responsive, portfolio-ready travel website built with **HTML5, CSS3 and vanilla JavaScript**.

## Highlights
- Full-screen destination hero slider
- Responsive navigation and mobile menu
- Destination/package filtering
- Live package search
- Favourite/save interaction
- Booking enquiry form with frontend validation
- Login modal demo
- Gallery lightbox
- Testimonial slider
- Contact form demo
- Responsive design for desktop, tablet and mobile
- Photo-realistic travel imagery

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
- Google Fonts

## How to Run
Open `index.html` directly in a browser, or use VS Code with the Live Server extension.

## Portfolio Talking Points
- Built a responsive travel landing page using semantic HTML.
- Created reusable card layouts and responsive CSS Grid/Flexbox systems.
- Added interactive filtering, search, sliders, modals, favourites and lightbox functionality with vanilla JavaScript.
- Used local relative asset paths so the project can be hosted on GitHub Pages.
- Designed the interface around a realistic travel-booking user journey.

## Future Enhancements
A future version could connect the booking/contact forms to a backend API, add authentication, and store trips in a database.
